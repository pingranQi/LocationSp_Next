# LocationSp_Next 3.2.3

## 功能与体验
- 增强坐标输入：支持经纬度文本、中文逗号、geo URI、常见地图坐标链接及剪贴板粘贴。
- 增加 GPX 路线导入与导出，支持 GPX 1.0 / 1.1 的轨迹、分段、路线点和航点读取；导入采用安全 XML 配置并限制文件大小与点数。
- 改进路线点编辑与路线播放数据处理，支持路线简化、语义路点保留及跨日期变更线坐标处理。
- 增加路线场景数据编解码与校验。

## 数据可靠性
- 路线 JSON 读写保留等待时长、海拔和时间戳等元数据，并兼容旧版仅含经纬度的数据。
- 路线导入先完成校验再批量保存，避免校验或持久化失败时只导入部分路线。
- 为已保存路线保留数据库 ID，使同名路线可独立识别和删除。
- 拒绝非法坐标、负时间戳及超出限制的输入数据。
- 补充坐标解析、GPX、路线 JSON、场景数据和路线简化相关单元测试。

## 构建与验证
- GitHub Actions 验证包括定向与全量单元测试，以及 Android 构建。
- 真机、不同 Android ROM 和 LSPosed 作用域下的系统 Hook 行为仍需在目标设备上单独验证。

## 安装包说明
- `LocationSp_Next-scoped-*`：在 LSPosed 作用域中选择需要模拟的目标应用。
- `LocationSp_Next-global-*`：全局方案，对系统进程生效。
- 两种方案二选一；绝大多数设备选择 `arm64-v8a`，32 位设备选择 `armeabi-v7a`。
- 正式发行包由仓库 Release 工作流使用配置的发布密钥签名；请核对随包发布的 `SHA256SUMS`。
