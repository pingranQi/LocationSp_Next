## 功能与优化
- 路线段定位改为二分查找，常规路线位置查询从 O(n) 优化至 O(log n)。
- 路线位置采用大圆弧插值，改善高纬度及跨日期变更线路线的定位精度。
- 跳过轨迹记录中的重复静止点，并基于不可变路线快照计算几何数据。

## 修复与可靠性
- 坐标转换和路线构造增加 NaN、无穷值及经纬度范围校验。
- GCJ-02 反向转换采用有界迭代收敛，提高转换往返精度。
- 保存路线在时间戳相同时使用稳定的次级排序。
- 增加坐标转换、路线插值、非法输入及重复 GPS 点回归测试。
- CI 验证覆盖 feature 分支，并取消同一分支上过时的验证任务。

## 安装包说明
- `LocationSp_Next-scoped-*`：非全局方案，在 LSPosed 作用域中勾选需要模拟的应用。
- `LocationSp_Next-global-*`：全局方案，对所选系统进程生效。
- 两种方案二选一；绝大多数设备选择 `arm64-v8a`，32 位设备选择 `armeabi-v7a`。
